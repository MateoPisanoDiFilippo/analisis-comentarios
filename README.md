 Análisis de Comentarios de Texto

 Integrantes

Escenario
Escenario C – Procesamiento Básico de Comentarios de Texto
UTN - Tecnicatura Universitaria en Programación - 2026

 Dataset
Archivo CSV con comentarios de usuarios. Se analiza la frecuencia
de palabras y se clasifican los comentarios como positivos o negativos
mediante palabras clave.

 Estructura del repositorio
- /datos : archivo CSV con los comentarios
- /scripts : script Python con el análisis
- /resultados : informe de texto con los resultados

 Cómo ejecutar
1. Clonar el repositorio
2. Abrir Google Colab
3. Ejecutar scripts/analisis.py desde la carpeta raíz del proyecto
